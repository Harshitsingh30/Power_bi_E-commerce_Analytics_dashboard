# 🛒 E-Commerce Sales & User Analytics Dashboard

## 🎯 Objective

The objective of this project is to analyze sales performance and user activity patterns in an e-commerce business in order to:
- Understand overall sales performance and revenue trends.
- Analyze user activity and purchasing behavior.
- Identify strong and weak areas of the business.
- Support data-driven business decisions and improve overall performance.

## ❓ Business Questions Solved
1. What is the total sales & revenue generated?
2. Which products and categories perform best?
3. How do sales trend over time (monthly / yearly)?
4. Which regions contribute the most sales?
5. How do users behave (activity, repeat purchases, etc.)?

## 🗂️ Data Source
The dataset used for this project was sourced from Kaggle.

## 🛠️ Tools Used

| Tool | Purpose |
|------|---------|
| **Microsoft Excel** | Data summarization |
| **Power Query Editor** | Data cleaning and transformation |
| **SQL (MySQL)** | Database creation and data analysis |
| **Power BI** | KPIs and interactive dashboard |

## 🔄 Project Workflow

```
Raw Data (Kaggle)
      │
      ▼
 Excel ──────────────► Data summarization
      │
      ▼
 Power Query Editor ─► Data cleaning & transformation
      │
      ▼
 MySQL ──────────────► Database creation & SQL analysis
      │
      ▼
```

### 1️⃣ Excel: Data Summarization
Summarized the data to understand its structure and quality.

### 2️⃣ Power Query Editor: Data Cleaning & Transformation
Cleaned and transformed the data before analysis.

### 3️⃣ MySQL: Database & Analysis
1. Created an **E-Commerce database** in MySQL.
2. Imported the CSV files into database tables.
3. Performed data analysis using SQL queries.

### 4️⃣ Power BI: Dashboard
- Built an interactive dashboard to visualize sales and user analytics.
- Created measures and KPIs to track business performance.

## 💡 Key Insights:
● The Pet Supplies category generates the highest number of orders, while the Electronics category generates the highest revenue.

● The Pet Supplies, Toys, and Clothing categories have the highest order quantities.

● Product views are high, but the purchase rate is comparatively low.

● Verdand Isles City has the highest number of users, whereas Krypton City has the lowest number of users.

● Male users contribute a slightly higher percentage of total users compared to female users.


## ✅ Recommendations
● Increase the purchase conversion rate by offering targeted discounts and promotional campaigns.

● Maintain adequate inventory levels for high-demand categories such as Pet Supplies, Toys, and Clothing.

● Reduce product return rates by improving product quality, descriptions, and delivery accuracy.
